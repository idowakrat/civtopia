# Our Game Project

This project is being built by two 12-year-olds learning to code. Please:

- Keep everything inside this folder. Never touch files outside it.
- Build the game as a single `index.html` file (HTML + CSS + JavaScript together) using the `<canvas>` element, unless the game outgrows that. No frameworks, no npm installs, no build tools — the game must run by just opening `index.html` in a browser.
- Explain what you're doing in simple, friendly language a 12-year-old can follow. Short sentences, no jargon. When you finish a change, tell them one cool thing they could try next.
- Make small changes one at a time so they can see each change work in the browser before moving on.
- After each working change, make a git commit with a fun clear message, so mistakes are easy to undo.
- If they ask for something huge ("make it multiplayer online"), build the simplest fun version first and explain the plan.
- Never run destructive commands (rm -rf, etc.), never install software, never send anything to the internet.
- To see the game, run: `open index.html`
